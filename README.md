# QA Project: Cash Register Support Form & REST API Testing

## Описание проекта

Данный проект представляет собой тестирование веб-формы обращения в техническую поддержку кассового оборудования и REST API.

В рамках проекта проведено исследовательское и функциональное тестирование формы, составлен чек-лист на **46 проверок**, разработаны позитивные и негативные API-тест-кейсы для **2 REST API endpoints** на основе OpenAPI-спецификации, оформлены баг-репорты и рекомендации по улучшению продукта.

## Покрытие тестирования

### Web

Проверены обязательные поля, позитивные и негативные сценарии ввода, валидация email и телефона, заводской номер ККТ, регион, CAPTCHA, выпадающие списки, отправка формы, защита от дублирующей отправки и отображение ошибок.

### REST API

Проверены endpoints:

- `POST /v1/kkt/user/reg`
- `GET /v1/kkt/user/kkt/{serial_number}`

Покрыты позитивные и негативные сценарии, JWT-авторизация, request/response, типы данных, некорректные токены, HTTP-методы, Content-Type и инъекционные значения.

## Инструменты и технологии

- **Виды тестирования:** функциональное, негативное, исследовательское, black-box testing
- **API:** REST API, HTTP, JSON, JWT
- **Документация API:** OpenAPI / Swagger
- **Инструменты:** Chrome DevTools, Postman, Swagger
- **Тестовая документация:** чек-листы, тест-кейсы, баг-репорты
- **Окружение:** Windows 10 Pro / Google Chrome
